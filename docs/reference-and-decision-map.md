# Reference and Decision Map

> **Purpose:** Complete evidence ledger tracing every architectural, visual, structural, interactive, accessible, and performance decision across the 10 frontend specs back to exact sources, categorized without altering provenance tags:
> - `[REQUIREMENT]` - Explicit instruction from the user prompt or standing workspace directives.
> - `[OBSERVED]` - Direct visual/technical observation verified in uploaded reference screenshots, backend docs, or inspected repository files.
> - `[INFERRED]` - Technical or structural consequence derived from combining user requirements with existing backend/route realities.
> - `[RECOMMENDED]` - Proactive best-practice enhancement consistent with project constraints and product category.
